⑥ Guardrails cross-cutting

Data
  • Synthetic data only
  • PII pseudonymisation (names, phone, PAN, accounts)
  • PII-leak check before every model call
Model
  • Prompt-injection screen; remarks treated as untrusted data
  • Schema validation + repair retry
  • Grounding check: citations must exist, risk claims must be supported
  • Rules-score risk floor (model can raise, never lower)
  • Prompt versioning, temperature 0
Action
  • Deterministic routing: auto-close only if PROCEED, risk<30, confidence≥0.8, no flags; escalate if risk≥70 or critical rule
  • Action allow-list; blocking only by L2
  • Mandatory reason for overrides
  • 10% QA sampling of auto-closures; 15-min SLA

⑦ Human oversight & governance

  • HL1 analyst decides H-route cases
  • EL2 senior decides escalations & blocking
  • Auditor: read-only, verifies hash chain
  • Model benchmark before adoption (3+ open models)
